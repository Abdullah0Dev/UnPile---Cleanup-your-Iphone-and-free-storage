## Start with Apple's built-in Duplicates album

Before downloading any app, I always recommend checking what Apple already provides.

If you're using a recent version of iOS:

1. Open **Photos**.
2. Scroll to **Utilities**.
3. Tap **Duplicates**.
4. Review the suggested matches.
5. Tap **Merge**.

For smaller libraries, this works surprisingly well.

If you only have a few duplicate photos, Apple's built-in tool may be all you need.
